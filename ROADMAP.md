# Roadmap

## Pre-alpha 0.1

- Playable local world.
- Editable block registry and textures.
- Basic mod API.
- Chiptune audio.
- GitHub-ready project files.

## Pre-alpha 0.2

- Better terrain chunks and view distance controls.
- Simple inventory counts.
- Crafting bench prototype.
- Better lighting and day-night cycle.
- More original block and item textures.

## Pre-alpha 0.3

- Local world selection.
- Mod manifest files.
- Entity prototype.
- Save migration format.

## Later

- Optional multiplayer.
- Default listed server through a privacy-aware endpoint.
- Dedicated server tooling.
- Public mod loader API documentation.
