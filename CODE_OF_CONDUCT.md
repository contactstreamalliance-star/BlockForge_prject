# Code of Conduct

Voxel Frontier Alpha should be a friendly place to build, learn and experiment.

Participants are expected to:

- Be respectful and constructive.
- Welcome beginners and experienced contributors.
- Give feedback about the work, not personal attacks.
- Avoid harassment, hate speech, threats, spam and intentionally disruptive behavior.

Maintainers may hide, reject or remove contributions that make the project unsafe or hostile.
