# Contributing

Thanks for helping Voxel Frontier Alpha grow.

## Before contributing

- Keep code and assets original or clearly open licensed.
- Do not submit Minecraft assets, decompiled code, copied gameplay data, logos or brand material.
- Prefer small pull requests with one focused change.
- Test the game locally before opening a pull request.

## Local setup

```powershell
npm start
```

Open the local address shown by the server.

## Project style

- Put engine code in `src/`.
- Put editable game data in `assets/`.
- Put optional extensions in `mods/`.
- Keep files uncompressed when possible so contributors can review changes directly.

## Pull requests

Describe what changed, how to test it, and whether assets or modding APIs are affected.
