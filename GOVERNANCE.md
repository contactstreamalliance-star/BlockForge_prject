# Governance

Voxel Frontier Alpha starts as a small experimental project.

## Maintainers

Maintainers review pull requests, protect project licensing and decide releases.

## Project rules

- Keep the project independent and original.
- Do not accept copied Minecraft assets, code, names or branding.
- Prefer open formats and editable source files.
- Keep modding APIs documented when they change.

## Decision process

For small changes, maintainers can decide directly in pull requests. For larger gameplay, architecture or licensing changes, open an issue first so contributors can discuss the direction.
